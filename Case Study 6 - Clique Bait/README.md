# Clique Bait SQL & Power BI Case Study Analysis

## Overview

This project analyzes digital customer behavior, product interactions, and marketing campaigns for Clique Bait using SQL and Power BI.

The goal is to understand customer journeys, digital engagement, product funnel performance, and campaign effectiveness using data from the Clique Bait platform.

## SQL Files

The SQL analysis is organized into the following files:

1. `01_data.sql` - Creates and populates the database with the case study dataset
2. `02-Digital_Analysis.sql` - Analyzes digital customer behavior and website interactions
3. `03-Product_Funnel_Analysis.sql` - Analyzes product funnel performance and customer conversion
4. `04- Campaigns_Analysis.sql` - Analyzes marketing campaigns and their performance
