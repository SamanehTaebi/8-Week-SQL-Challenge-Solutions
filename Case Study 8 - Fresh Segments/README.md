# Fresh Segments SQL & Power BI Case Study Analysis

## Overview

This project analyzes customer interests and segment data for Fresh Segments using SQL and Power BI.

The goal is to explore customer interests, analyze segment performance, and investigate the relationship between customer interests and segment classifications.

## Dataset

The dataset contains information about customer interests, segments, and index values.

The analysis uses data related to:

* Customer interests
* Interest categories
* Segments
* Segment sizes
* Index values
* Monthly interest data

## SQL Files

The SQL analysis is organized into the following files:

1. `data.sql` - Creates and populates the database with the case study dataset
2. `01-Data_Exploration_and_Cleansing.sql` - Explores and cleans the dataset
3. `02-Interest_Analysis.sql` - Analyzes customer interests and interest-related metrics
4. `03-Segment_Analysis.sql` - Analyzes customer segments and segment performance
5. `04-Index_Analysis.sql` - Analyzes index values and segment-interest relationships
