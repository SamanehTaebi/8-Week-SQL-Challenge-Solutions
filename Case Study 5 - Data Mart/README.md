# Data Mart SQL & Power BI Case Study Analysis

## Overview

This project analyzes customer sales and transaction data for Data Mart using SQL and Power BI.

The goal is to investigate changes in sales performance over time, compare sales before and after major events, and identify the impact of the February 2020 sustainability changes on the business.

## Dataset

The dataset contains information about Data Mart's weekly sales across different regions, platforms, customers, and product segments.

The analysis uses data related to:

* Weekly sales
* Regions
* Platforms
* Customer demographics
* Product segments
* Transactions

## SQL Files

The SQL analysis is organized into the following files:

1. `data.sql` - Creates and populates the database with the case study dataset
2. `01_data_cleaning.sql` - Cleans and prepares the raw data for analysis
3. `02_Data_Exploration.sql` - Explores the dataset and analyzes overall sales trends
4. `03_Before_&_After_Analysis.sql` - Compares sales performance before and after the February 2020 sustainability changes
5. `04_Bonus_Qestions.sql` - Answers the bonus questions from the case study
6. `advanced_dynamic_analysis_bonus_question.sql` - Performs an advanced dynamic analysis as an additional bonus question
